ARCADIA V DEMO — نسخه چندنفره Wi-Fi محلی (LAN)

این نسخه برای بازی روی یک شبکه Wi-Fi طراحی شده است؛ نیازی به اینترنت یا هاست ابری نیست. یک کامپیوتر میزبان، سرور بازی را اجرا می‌کند و بقیه دستگاه‌ها با مرورگر به IP میزبان وصل می‌شوند. همه بازیکنان در نسخه فعلی یک دولت و جهان مشترک را مدیریت می‌کنند (Co-op)، نه کشورهای جداگانه PvP.

راه‌اندازی روی کامپیوتر میزبان (Windows)
1) Node.js نسخه 18 یا جدیدتر را از https://nodejs.org نصب کن.
2) پوشه arcadia_online را Extract کن.
3) فایل START-LAN.bat را دوبار کلیک کن. بار اول بسته‌های لازم نصب می‌شوند و سرور اجرا می‌شود.
4) در پنجره سیاه، آدرس‌هایی شبیه http://192.168.1.5:3000 نمایش داده می‌شود.
5) روی کامپیوتر میزبان، http://localhost:3000 را باز کن.
6) دوستان باید به همان Wi-Fi وصل باشند و آدرس IP نمایش‌داده‌شده در مرحله 4 را در مرورگر وارد کنند.
7) میزبان «ساخت اتاق جدید» را می‌زند و کد اتاق را به دوستان می‌دهد. دوستان با همان کد وارد می‌شوند. سپس میزبان «ورود به بازی» را می‌زند و بازی را شروع می‌کند.

اگر دوست‌ها وصل نشدند
- مطمئن شوید همه به یک Wi-Fi وصل هستند و شبکه Guest / مهمان نیست.
- هنگام اولین اجرا، در Windows Firewall اجازه دسترسی Node.js به شبکه Private را بدهید.
- در صورت نیاز Windows Defender Firewall را برای پورت TCP 3000 در شبکه Private مجاز کنید.
- برای پیدا کردن IP: در CMD دستور ipconfig را اجرا کنید و IPv4 Address کارت Wi-Fi را بخوانید.
- از 127.0.0.1 یا localhost روی دستگاه دوستان استفاده نکنید؛ آن‌ها باید IP میزبان را وارد کنند.
- اگر روتر گزینه AP Isolation / Client Isolation دارد، آن را خاموش کنید.

نکته‌ها
- سرور باید تا پایان بازی روی کامپیوتر میزبان روشن بماند.
- این روش فقط داخل همان شبکه محلی کار می‌کند؛ بازی از بیرون خانه/شبکه قابل دسترسی نیست.
- در نسخه آزمایشی وضعیت بازی در حافظه سرور است و با بستن سرور، اتاق از بین می‌رود. برای نگه‌داشتن پیشرفت، میزبان از بخش بایگانی فایل JSON خروجی بگیرد.
- همه بازیکنان در حال حاضر کنترل مشترک دارند؛ بهتر است برای جلوگیری از تداخل، نوبت‌ها را هماهنگ جلو ببرید.
